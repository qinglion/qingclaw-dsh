# 青狮龙虾几何品牌延展

[English](README.md) | 中文

本方案把青狮龙虾视为青狮主品牌的产品延展，而不是一个独立吉祥物。

## 设计规则

- 保留原青狮的圆形主体、右侧负空间、下半圆与折叠平面。
- 在右侧添加一个圆润的主体延展。
- 将继承的圆形负空间延续为一个宽阔的圆头开口。因此，只有在近距离观察时，这个延展才会呈现为两个柔和的钳状瓣。
- 保持主色 `#4BB6B0`；仅在大尺寸折叠平面上保留 `#54B4AF → #48707A`。
- 不添加动物脸、眼睛、耳朵、写实龙虾解剖结构、描边、字母或字标。

预期识别顺序为：先识别青狮，再识别青狮龙虾。

## 文件

- `qingclaw-open-claw-mark.svg`——带继承折叠平面的透明大尺寸标志。
- `qingclaw-open-claw-micro.svg`——用于 16–34 px 界面的实心微型标志；有意移除折叠平面。
- `qingclaw-open-claw-app-icon.svg`——深色圆角方形应用图标。
- PNG 文件是渲染后的设计预览，不是最终生产导出文件。
