# QingClaw geometric brand extension

English | [中文](README.zh.md)

This concept treats QingClaw as a product extension of the Qinglion master brand, not as a separate mascot.

## Design rule

- Preserve the original Qinglion circular body, right-side negative space, lower semicircle and folded plane.
- Add one rounded body extension on the right.
- Continue the inherited circular negative space into one wide round-ended opening. The extension is therefore read as two soft claw lobes only at close range.
- Keep the master color `#4BB6B0`; retain `#54B4AF → #48707A` only on the large-format folded plane.
- Add no animal face, eyes, ears, literal lobster anatomy, outline, letter or wordmark.

The intended reading order is: Qinglion first, QingClaw second.

## Files

- `qingclaw-open-claw-mark.svg` — transparent large-format mark with the inherited folded plane.
- `qingclaw-open-claw-micro.svg` — solid micro mark for 16–34 px UI use; the folded plane is intentionally removed.
- `qingclaw-open-claw-app-icon.svg` — dark rounded-square application icon.
- PNG files are rendered design previews, not final production exports.
