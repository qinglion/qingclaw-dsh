# 青狮创作者中心

[English](README.md) | 中文

## 概述

创作者和管理员可以从侧栏打开内置的创作者中心。「我的插件」显示个人私服包和各版本，可选定版本申请市场上架。发包直接使用当前登录的青狮账号。

「我的插件」按市场上架标题列出每个包，并在标题下显示包名。识别到插件工程后，会话顶部显示「发布」页，提供项目详情和发布历史。点击主按钮会向当前会话发送发布请求。

## 模型体验

### 发布一个包

#### 模型看到的内容

发布按钮请求使用内置的 `qingclaw-plugin-publish` 技能，指定包目录和确切版本。用自然语言要求发布时使用同一技能。技能向 `qingclaw_publish_package` 工具提供当前账号标识。

#### Token 影响

发布指令带上本地目录、包名和版本。加载技能会补充发布步骤和非保密的账号标识。工具核对归档后返回包名和版本。客户端直接向官网获取发布凭据；读取私服（版本历史与发布前的版本核对）使用工作台 Host 服务用同一登录态换来的账号令牌。

#### KV 缓存影响

包列表和上架状态只在界面展示。发布指令和加载的技能内容会追加到会话历史。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 发布与上架申请只接受 `@qinglion/` 范围内的包名，且版本必须已存在于青狮私服。
- 共享存量账号发布的包没有已核实的所有者，需要管理员指定维护者后才会出现在创作者中心。

<a id="dev-note"></a>
### 开发备注

客户端与 Host 测试覆盖包列表、上架申请、发布历史和发布工具对账号响应的处理。
