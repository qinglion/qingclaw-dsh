# 青狮创作者中心

[English](README.md) | 中文

## 概述

创作者与管理员在侧栏拥有一个工作台：列出该账号的 npm 包及其版本，为选中的版本申请市场上架。我的插件按市场上架标题展示包，并在下方保留包名；本地项目列出已注册的工作区及其根清单声明的插件。右侧栏起始页提供“工作台发布”卡片，点名当前会话目录声明的插件，把发布请求写进该会话，并请它提升补丁版本、发布并提交改动。

## 模型体验

### 发布一个包

#### 模型看到的内容

`qingclaw_publish_package` 工具对已登录的创作者在每个会话中都可用，不要求工作区根目录识别到插件。用户明确要求发布时加载内置的 `qingclaw-plugin-publish` 技能；技能给出 `@qinglion` 包名、确切版本和工具需要的账号标识。包目录相对会话自己的目录解析，所以通过分支创建的会话发布的是它自己的工作树。已知目录时直接传；否则复用本会话上次发布的目录，再否则按包名和版本找到唯一声明它的目录，同深度出现多个就列出候选由用户选择。

#### Token 影响

工具参数带上工作区相对目录、包名和版本。加载技能会补充发布步骤和非保密的账号标识。工具核对从该目录打出的归档后返回包名和版本。客户端直接向官网获取发布凭据；读取私服使用工作台 Host 服务用同一登录态换来的账号令牌。

#### KV 缓存影响

包列表和上架状态只在界面展示。发布请求和加载的技能内容会追加到会话历史。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 「本机项目」只读取每个工作区的根目录清单。集合型工作区里的包通过指定其目录发布，而不经过发现。
- 发布要求解析出的包目录含可识别的插件清单，且包名与版本和请求一致。未指定目录时取最浅的同名同版本目录；同一深度出现多个时拒绝并列出候选。
- 会话选定的包目录保存在 Host 进程内。客户端重启后，该会话第一次发布会重新选择一次。
- 「发布」页一次只解析一个目录：会话目录，或用户填写的子目录；不会枚举其下的所有包。
- 关联保存在本机客户端的 localStorage 中、按会话区分；换机器不会带过去。
- 发布需要有效的专业版授权：免费账号拿不到发布授权，工具会提示创作者升级专业版。
- 发布与上架申请只接受 `@qinglion/` 范围内的包名，且版本必须已存在于青狮私服。
- 上架申请要求版本声明 `qingclaw.name` 与 `qingclaw.description`；工作台还需要 `qingclaw.workbench.icon` 和至少两张 `previews`。
- 共享存量账号发布的包没有已核实的所有者，需要管理员指定维护者后才会出现在创作者中心。

<a id="dev-note"></a>
### 开发备注

客户端与 Host 测试覆盖包列表、上架申请、工作区发现，以及发布工具对账号响应的处理。
